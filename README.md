# 🛒 E-Commerce Website

## 📌 Project Overview

This project is a fully functional E-commerce web application developed to simulate an online shopping platform. It allows users to browse products, add items to the cart, manage quantities, and view total pricing.

The application focuses on delivering a smooth user experience with a clean interface and dynamic cart functionality.

---

## 🎯 Objectives

* Build a responsive and user-friendly e-commerce interface
* Implement cart functionality with real-time updates
* Simulate product browsing and purchasing workflow
* Enhance frontend and backend integration skills

---

## 🧠 Technologies Used

* **Frontend:** HTML, CSS, JavaScript
* **Backend (if used):** Python (Flask)
* **Database (if used):** MySQL / SQLite
* **Tools:** VS Code, Git, GitHub

---

## ⚙️ Features

* 🛍️ Browse products by categories (Menswear, Womenswear, Electronics, etc.)
* ➕ Add items to cart
* ➖ Increase / decrease product quantity
* 💰 Dynamic total price calculation
* ❌ Remove items from cart
* 🔐 User login interface (if implemented)
* 📱 Responsive design for better user experience

---

## 📊 How It Works

1. User browses products from different categories
2. Selects items and adds them to the cart
3. Cart updates quantity and total price dynamically
4. User can modify or remove items before checkout
